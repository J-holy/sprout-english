# 새싹스쿨 설계

새싹영어를 시작으로 **새싹수학**, **새싹한자** 같은 과목을 하나씩 더해 가는 어린이 학습 서비스 **새싹스쿨**의 설계예요.
앞으로 이 저장소에서 하는 작업은 이 문서를 기준으로 해요. 바뀌는 결정이 있으면 이 문서부터 고쳐요.

## 1. 원칙

1. **가족 계정 하나, 아이 프로필 하나로 모든 과목을 써요.** 로그인, 아이 프로필, 아바타, 별, 결제는 과목마다 따로 두지 않아요.
2. **과목은 끼워 넣는 모듈이에요.** 새 과목을 만들 때 공통 부분(화면 틀, 레슨 진행, 복습, 보충 학습, 게임 틀, 상점, 부모 리포트)은 다시 만들지 않고, 그 과목의 내용과 문제 유형만 만들어요.
3. **지금의 새싹영어는 깨지지 않게 옮겨요.** 아이들의 학습 기록과 별은 그대로 이어져야 해요. 데이터 구조를 바꿀 때는 항상 옛 기록을 새 구조로 옮기는 코드를 함께 넣어요.
4. **빌드 없이 도는 지금의 장점은 지켜요.** 라즈베리파이 한 대와 GitHub Pages(서버 없는 체험판)에서 모두 돌아가야 해요.

## 2. 서비스 구조

```
새싹스쿨 (school.도메인)
├─ 홈: 과목 고르기 · 오늘의 학습 · 아이 프로필 · 별 상점 · 놀이터
├─ /english  새싹영어  (지금 서비스)
├─ /math     새싹수학
└─ /hanja    새싹한자
부모페이지: 아이별 · 과목별 리포트, 결제 관리
```

- **주소는 한 도메인 아래 경로로 나눠요.** `saessak.도메인/english`처럼 두면 로그인 쿠키, 결제, PWA(홈 화면 앱)가 하나로 이어져요. 과목마다 하위 도메인(`english.도메인`)을 쓰면 로그인과 쿠키를 따로 맞춰야 해서 운영이 복잡해져요.
- **도메인은 새싹스쿨 이름으로 사요.** 이번에 살 도메인은 영어 전용 이름(예: sprout-english)이 아니라 새싹스쿨 이름이어야 나중에 바꾸지 않아도 돼요. 영어 전용 도메인이 이미 있다면 `/english`로 넘겨주는 주소로만 써요.
- **첫 화면**은 새싹스쿨 홈이고, 아직 과목이 영어 하나뿐일 때는 홈에서 바로 새싹영어로 들어가게 해요(과목 카드가 하나만 보이면 건너뛰기).

## 3. 공통(플랫폼)과 과목(모듈) 나누기

| 공통: 새싹스쿨이 한 번만 가짐 | 과목마다: 새싹영어·수학·한자가 각자 가짐 |
|---|---|
| 가족 계정, 로그인(이메일·카카오·구글), 세션 | 단계·레벨 구성 (영어 A~Z 26레벨 등) |
| 아이 프로필: 이름, 나이, 아바타, 꾸미기 | 학습 내용 (단어·문장·스토리북 / 수·연산 / 한자) |
| 별 지갑, 별 상점, 스티커북, 레벨 배지 판 | 문제 유형 (영어: 말하기·철자 / 수학: 숫자 패드·수직선 / 한자: 획순 쓰기) |
| 연속 학습일(스트릭), 하루 목표, 성장 나무 | 과목 게임 (영어: 풍선·징검다리 / 수학: 수 세기 등) |
| 레슨 진행 엔진, 채점, 오답 노트, 망각 곡선 복습, 보충 학습 | 레벨 테스트 문항 |
| 놀이터 틀(점수·최고 기록·별 지급) | 워크시트 내용 |
| 부모페이지 틀, 알림, 리포트 틀 | 리포트에 보여 줄 영역별 지표 |
| 결제, 쿠폰, 무료 체험, 관리자 | 무료로 여는 범위 (영어는 1~2단계) |
| 음성(TTS·STT), 삽화 만들기 도구, 디자인 | 쓰는 목소리 (영어 원어민 / 한자 음훈은 한국어) |

**별과 아바타는 과목을 넘어 하나로 모아요.** 영어로 모은 별로 산 왕관을 수학에서도 쓰고 있으면, 아이가 여러 과목을 오가도 보상이 끊기지 않아요.

## 4. 데이터 구조

### 4-1. 아이 프로필 (화면 저장소와 서버 `users.state`)

지금은 영어 기록(`progress`, `wrong`, `srs`, `stories` 등)이 프로필 바로 아래에 섞여 있어요. 공통과 과목을 나눠요.

```js
profile = {
  id, name, age, avatar, wear, createdAt,          // 공통: 누구인지·꾸미기
  stars, owned, starLog, badges, streak, dailyGoal,  // 공통: 보상·습관
  subjects: {
    english: { progress, wrong, srs, stories, placed, startLevel, difficulty, recentScores, skills, games, certs, recent },
    math:    { ... },
    hanja:   { ... },
  },
}
```

- **옮기기**: `normalizeProfile`에서 `subjects`가 없으면 지금의 영어 필드를 `subjects.english`로 옮겨요. 서버에도 같은 옮기기를 한 번 실행하는 스크립트를 둬요.
- **레벨 배지**처럼 과목마다 따로인 기록은 키에 과목을 붙여요(`badges['english:A']`).
- **브라우저 저장 키** `sprout-english.v2`는 `saessak-school.v1`로 바꾸고, 처음 열 때 옛 키를 읽어 옮겨요.
- 학습 기록이 커지면(지금 한도 1.8MB) 과목별 기록을 `progress` 표로 따로 저장하는 것을 검토해요. 과목이 3개가 될 때까지는 지금처럼 한 덩어리로 충분해요.

### 4-2. 서버 표

| 표 | 바뀌는 점 |
|---|---|
| `users`, `identities`, `sessions` | 그대로 (가족 계정은 공통) |
| `memberships` | **과목별 이용권**으로: `(user_id, product, kids, months, until, …)`. `product`는 `english`, `math`, `hanja`, `all`(전 과목 묶음) |
| `payments` | `product` 열을 더하고, 상품 이름을 `새싹스쿨 · 새싹영어 한 자녀 6개월`처럼 |
| `reviews` | `subject` 열을 더해 과목별 후기 |
| 나머지 | 그대로 |

### 4-3. 이용권 판단

- 지금의 `isFreeLevel(lv)`과 `needsPlus(lv)`를 **과목 + 레벨**로 바꿔요: `needsPlus('english', 'F')`.
- 이용권 확인은 **지금 과목 이용권 또는 `all` 이용권**이 있으면 통과예요.

## 5. 요금 (안)

결제 금액은 지금처럼 **항상 서버에서 계산**해요(`server/lib/pricing.js`). 화면 쪽 표와 같은 값을 써요.

| | 한 자녀 | 두 자녀 |
|---|---|---|
| 한 과목 | 29,900원 (지금과 같음) | 44,900원 |
| 두 과목 묶음 | 44,900원 | 64,900원 |
| 전 과목 묶음 | 54,900원 | 79,900원 |

- 6개월·12개월 할인과 웰컴쿠폰 20%는 지금 규칙을 그대로 써요.
- 과목마다 **무료로 열어 두는 처음 단계**가 있어요(영어는 알파벳·파닉스). 무료 단계로 과목을 맛보고, 묶음으로 넘어가게 해요.
- 금액은 아직 정하지 않은 **안**이에요. 출시 전에 확정해요.

### 6-2. 과목 모듈의 약속 (`subjects/<id>/subject.js`)

공통 코드는 과목 이름을 몰라요. 과목은 아래 모양의 객체 하나를 등록해요.

```js
School.registerSubject({
  id: 'english', name: '새싹영어', color: '#58c472', icon: '🔤',
  stages: [...],                          // 단계와 레벨, 무료 범위
  levelItems(level) { ... },              // 그 레벨에서 배울 항목
  questions(item, ctx) { ... },           // 항목 → 문제들 (공통 유형 + 과목 유형)
  questionTypes: { speak: render, ... },  // 이 과목만의 문제 유형 그리는 방법
  games: [...],                           // 놀이터에 더할 과목 게임
  placement: { ... },                     // 레벨 테스트
  report(subjectState) { ... },           // 부모 리포트에 보여 줄 지표
  worksheet(level) { ... },
  voice: 'en-US',                         // 기본 목소리
});
```

- **과목 파일은 그 과목에 들어갈 때 불러요.** 첫 화면을 가볍게 하고, 과목이 늘어도 처음 여는 속도가 느려지지 않게 해요.
- 지금 코드는 전역 변수로 이어진 일반 스크립트예요. 옮기는 김에 **브라우저 기본 ES 모듈**(`<script type="module">`, `import`)로 바꿔요. 빌드 도구 없이도 돼서 라즈베리파이·GitHub Pages 그대로 써요.

### 6-3. 과목별 문제 유형 예시

| 과목 | 과목만의 문제 유형 | 공통 유형으로 되는 것 |
|---|---|---|
| 영어 | 따라 말하기(STT), 철자 타일, 듣고 쓰기 | 그림 고르기, 뜻 고르기, 문장 순서 |
| 수학 | 숫자 패드 입력, 수 세기(그림 묶음), 수직선, 시계 바늘 맞추기, 도형 고르기 | 답 고르기, 순서 맞추기 |
| 한자 | 획순 따라 쓰기, 음훈 듣고 고르기(하늘 천), 낱말 만들기(天地) | 뜻 고르기, 짝 맞추기 |

## 7. 이름과 브랜드

- **통합 이름**: 새싹스쿨 (영문 Saessak School). 마스코트 새싹이는 모든 과목에 같이 나와요.
- **과목 이름**: 새싹영어, 새싹수학, 새싹한자. 과목마다 대표 색을 하나씩 정해요(영어 초록, 수학 파랑·주황 계열, 한자 빨강·먹색 계열 등 — 출시할 때 확정).
- **따뜻한 크림·복숭아 바탕 색**(2026-10-30 적용)과 수채화 삽화체는 새싹스쿨 공통이에요.
- **코드 안의 이름**: 저장소와 서비스 이름 `sprout-english` → `saessak-school`, 라즈베리파이 경로 `/opt/saessak-school`, systemd `saessak-school.service`. 바꿀 때 옛 GitHub Pages 주소(`/sprout-english/`)는 새 주소로 넘겨줘요.
- 화면 글자 "새싹영어" 36곳은 공통 부분은 "새싹스쿨"로, 영어 과목 안에서는 "새싹영어"로 나눠요.

## 8. 음성과 그림

- **음성**: 영어는 지금처럼 원어민 AI 목소리. 한자 음훈(하늘 천)과 수학 문제 읽기는 **한국어 목소리**를 써요. `pregen-tts`가 과목별 문장을 `audio/<과목>/`에 따로 만들게 바꿔요.
- **그림**: `pregen-img`는 이미 책(스토리북)·단어·아이콘을 같은 그림체로 그려요. 과목 폴더(`img/<과목>/`)와 과목별 그림 목록을 받게 바꾸고, 공통 아이콘은 `img/common/`에 둬요.

## 9. 순서

| 단계 | 할 일 | 끝났다고 보는 기준 |
|---|---|---|
| **0. 도메인 (이번 주)** | 새싹스쿨 이름으로 도메인 구입. 새싹영어는 `/english` 아래로 | 새 도메인에서 지금 서비스가 열림 |
| **1. 플랫폼 나누기** | 프로필 데이터 `subjects.english`로 옮기기, `core/`·`subjects/english/` 폴더 나누기, ES 모듈, 새싹스쿨 홈, 부모페이지 과목 탭 | 화면과 기능은 지금과 똑같고, 옛 기록이 모두 이어짐 |
| **2. 결제** | 과목별 이용권과 묶음 요금 | 영어 이용권 기존 회원이 그대로 이용 |
| **3. 새싹수학 첫 판** | 수 세기 → 10까지 덧셈·뺄셈 → 100까지 수 → 시계·도형. 숫자 패드·수 세기 문제 유형 | 수학 1~2단계 무료 공개 |
| **4. 새싹한자 첫 판** | 8급 한자 50자, 획순 쓰기, 음훈 듣기 | 한자 1단계 무료 공개 |

1단계는 다른 단계의 바탕이라 가장 먼저 해요. 1단계 동안에는 아이들이 보는 화면이 바뀌지 않아요.
