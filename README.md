# 새싹영어 (Sprout English)

5~10세 어린이 영어 학습 서비스예요. 라즈베리파이 한 대로 운영할 수 있게 서버까지 포함되어 있고, 도메인만 연결하면 바로 쓸 수 있어요.

```
sprout-english/
├─ public/    화면 (HTML·CSS·JS, 빌드 필요 없음)
├─ server/    Node.js 서버: 계정·이메일 인증·SNS 로그인·결제·관리자·학습 기록 동기화 (SQLite 내장)
└─ deploy/    라즈베리파이 설치 스크립트, systemd, Caddy(HTTPS), 배포 가이드 ← 여기부터 보세요
```

## 바로 실행해 보기 (PC)
```bash
cd sprout-english/server
npm install
npm run dev
```
http://localhost:8080 에서 열려요.
- 개발 모드라 인증코드가 화면 오른쪽 아래에 보이고, 결제는 데모로 즉시 완료돼요.
- `ADMIN_EMAILS=me@example.com npm run dev` 처럼 실행하면 그 이메일이 관리자가 돼요.
- 서버 없이 `public/index.html`만 열어도 동작해요. 이때는 데이터가 그 브라우저에만 저장되는 데모 모드예요.

## 링크로 공유하기 (GitHub Pages)
GitHub에 올리면 `.github/workflows/pages.yml`이 `public/` 폴더를 자동으로 배포해요. 주소는 `https://<GitHub 아이디>.github.io/<저장소 이름>/` 형식이에요.
- GitHub Pages에는 서버가 없어서 사이트가 **체험용 데모 모드**로 열려요.
  - 화면 위쪽에 안내 띠가 보여요.
  - 가입·학습 기록은 방문자 브라우저에만 저장되고, 결제는 데모예요.
  - 인증코드는 화면 오른쪽 아래에 보여요.
- 실제 회원·결제 운영은 아래 라즈베리파이 서버로 해요.

## 라즈베리파이에 배포
👉 **[deploy/DEPLOY.md](deploy/DEPLOY.md)**
```bash
sudo ./deploy/install-pi.sh --domain 내도메인.kr --admin 내이메일@example.com           # 공유기 포트포워딩 + 자동 HTTPS
sudo ./deploy/install-pi.sh --domain 내도메인.kr --admin 내이메일@example.com --tunnel  # Cloudflare Tunnel (포트포워딩 없이)
```

## 주요 기능
| 영역 | 기능 |
|---|---|
| 첫 화면 | 가입 없이 바로 푸는 퀴즈, 3분 체험 레슨, 무료 레벨 진단, 부모 리포트 예시, 성장 단계 미리 듣기 |
| 메뉴 | 홈 · 📚 학습하기 · 💰 요금·할인 · 💬 후기 · 🙋 도움말 |
| 로그인·가입 | 비밀번호 없음. 이메일 6자리 인증코드(SMTP 발송) 또는 카카오·네이버·Google·Apple. 단계 표시, 최근 사용한 방법 표시 |
| 학습 | 8단계 26레벨 × 10일 = **260레슨** (하루 1레슨·주 5일이면 약 1년, 하루 2레슨이면 약 6개월), 레벨마다 9일 학습 + 1일 복습 |
| 콘텐츠 | 알파벳 그림 단어 78개, 파닉스 단어 72개, 문장 228개, 질문·대답 128쌍, 과거형 동사 54개, 스토리북 16권 |
| 학습 도구 | 8가지 문항 유형, 자동 난이도, AI 발음 코치, 놀이터 게임, 별 상점, 오답노트, 워크시트 인쇄 |
| 목소리 | 기기에서 가장 자연스러운 목소리를 자동 선택하고, 설정에서 직접 고를 수 있어요. 서버에 OpenAI·Google 키를 넣으면 AI 음성으로 읽어줘요 |
| 부모페이지 | 리포트, 학습 알림, 멤버십(결제 내역·자동갱신 해지·7일 환불), 쿠폰함, 워크시트, 설정(볼륨·난이도·PIN) |
| 결제 | 토스페이먼츠 자동결제(카드 등록 → 첫 결제 → 자동갱신 → 환불). 금액은 항상 서버가 계산 |
| 관리자 | 회원 검색, 멤버십 지급·회수, 체험 연장, 쿠폰·별 지급, 권한 관리, 후기 관리, 서버 상태, DB 백업 받기 |
| 운영 | 매일 자동 백업, 보안 헤더, CSRF 방지, 요청 제한, 세션 해시 저장 |

## 실제 리뷰 불만 → 개선한 점
| 리뷰 불만 | 개선 |
|---|---|
| 구독 상태와 해지 방법이 불명확해요 | 결제 내역, 자동갱신 해지, 7일 이내 환불을 버튼 하나로 처리해요 |
| 1년을 결제해야만 할인돼요 | 1개월 상품도 할인되고, 쿠폰을 모든 기간에 쓸 수 있어요 |
| 소리 크기가 들쭉날쭉해요 | 목소리와 효과음 볼륨을 따로 조절해요 |
| 너무 어렵거나 금방 지루해해요 | 자동 난이도와 놀이터 게임이 있어요 |
| 별을 어디에 쓰는지 몰라요 | 별 상점과 스티커북이 있어요 |
| 워크시트를 어떻게 받는지 몰라요 | 바로 인쇄하고 인쇄 기록이 남아요 |
| 리포트를 받으려면 카톡 연동이 필요해요 | 연동 없이 부모페이지에서 봐요 |
| 음성 인식이 아이 목소리를 잘 못 알아들어요 | 너그러운 채점이 기본으로 켜져 있어요 |
